# Web 客户端规则

- 唯一生产源码位于 `apps/web/public/`；不要手工创建或维护 `src/xuanxue/web/static/` 副本。
- Web 继续与 API 同域，保留 HttpOnly Cookie、CSRF、SSE 与轮询恢复语义。
- 生产发布物是独立静态包，不进入后端 wheel；后端和 Web 可以独立发布，但契约变更必须先保持向后兼容。
- 新 API 调用必须来自公开契约，不从后端数据库或内部 Python 对象推断字段。
- 前端不得展示或选择供应商、模型、提示词版本、分析路由、raw reasoning、usage 或成本。
- 目录搬迁已经完成；框架替换、API 层改造和视觉改版继续分开提交。
- 前端验收至少覆盖桌面、移动宽度、登录态、长任务、空/错状态和无横向溢出。
